Exibe parcelamento, descontos e juros por forma de pagamento em lojas WooCommerce.

== Description ==

Exibe a melhor parcela, a tabela de parcelamento, o preço no Pix e no boleto, as bandeiras de cartão, o desconto por quantidade e os descontos ou juros por forma de pagamento, inclusive no checkout. Inclui widgets para Elementor e shortcodes.

Fork open source do plugin Parcelas Customizadas para WooCommerce (obra original de MeuMouse.com), mantido por Frederico de Castro. Todos os recursos estão liberados, sem chave de licença.

Código-fonte, documentação e issues: https://github.com/fredpiuma/custom-installments-for-woocommerce

== Installation ==

1. Envie o arquivo `custom-installments-for-woocommerce.zip` em Plugins → Adicionar novo → Enviar plugin.
2. Ative o plugin.
3. Configure em WooCommerce → Custom Installments.

Se o plugin Parcelas Customizadas para WooCommerce estiver ativo, desative-o antes. As configurações dele são aproveitadas.
